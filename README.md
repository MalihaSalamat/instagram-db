# Instagram Clone

A simple Instagram-inspired social media front-end built with HTML, CSS, and JavaScript.

## Features
- Instagram-style navigation
- Stories section with profile images
- Feed layout with post cards
- Responsive mobile layout
- Supabase-ready JavaScript integration

## Tech Stack
- HTML
- CSS
- JavaScript
- Supabase

## Run locally
Open the project folder in a browser, or use a local static server.

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes
This project is a front-end prototype and may require a Supabase project and table setup for live post data.
